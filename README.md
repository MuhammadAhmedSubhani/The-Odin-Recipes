# Odin Recipes

A simple recipe website created as part of [The Odin Project](https://www.theodinproject.com/) Foundations course.

This project demonstrates basic HTML skills by creating a website that displays different food recipes, including their descriptions, ingredients, and step-by-step preparation instructions.

## Project Overview

The website contains a homepage with links to different recipes. Each recipe has its own dedicated page with information about the dish.

### Recipes Included
- **Burger** – A classic burger recipe with ingredients and preparation steps.
- **Pizza** – A homemade chicken pizza recipe with ingredients and baking instructions.

## Technologies Used

- HTML5
- Git
- GitHub

## Features

- Homepage displaying available recipes.
- Individual recipe pages.
- Recipe images.
- Recipe descriptions.
- Ingredients lists.
- Step-by-step cooking instructions.
- Navigation between the homepage and recipe pages.
